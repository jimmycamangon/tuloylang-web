# TuloyLang

TuloyLang is a free-to-use personal progress app for habits, workouts, and lightweight analytics.

## How data works

TuloyLang stores app data locally in the browser using `localStorage`. There is no cloud database, account system, or paid subscription required for the core app experience.

- `Export app data` creates a JSON backup of your current local data
- `Restore History` imports that JSON backup so users can recover progress later

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
